# دوره توسعه بک‌اند با FastAPI

نمونه‌کدها، تمرین‌ها و پروژه دوره شانزده‌جلسه‌ای توسعه بک‌اند با FastAPI،
برگزارشده در [مؤسسه فنی و آموزشی کادوس](https://kadoosedu.ir).

این دوره ادامه دوره «پایتون پیشرفته» است و آموزش زبان پایتون از صفر در آن
نیست. هر جلسه سه ساعت است و **حدود هفتاد درصد زمان کلاس به کار عملی**
می‌گذرد: نوشتن کد، اشکال‌زدایی، بازنویسی، آزمون و کار روی یک پروژه واقعی.
در طول دوره، ابزارهای پایتون پیشرفته مثل راهنمای نوع، `Annotated`، کلاس‌ها،
دکوراتورها، مدیر زمینه، مولدها و `async`/`await` بارها در عمل به کار می‌روند.

## پروژه دوره

از جلسه اول تا آخر، یک پروژه واقعی قدم به قدم ساخته می‌شود: **API مدیریت
آموزشگاه** (Training Center API) با کاربران، دوره‌ها، ثبت‌نام دانشجو و فایل‌های
درسی. هر جلسه یک قدم به همان پروژه اضافه می‌کند و آخرین پوشه هر جلسه، وضعیت
پروژه در پایان همان جلسه است:

```
جلسه ۱   هسته پروژه با پایتون خالص        جلسه ۹    ثبت‌نام، ورود و رمز امن
جلسه ۲   اولین API با FastAPI              جلسه ۱۰   توکن JWT و نقش‌ها
جلسه ۳   اعتبارسنجی با Pydantic            جلسه ۱۱   فایل، کوکی و CORS
جلسه ۴   تزریق وابستگی و ساختار پروژه      جلسه ۱۲   تبدیل کامل به async
جلسه ۵   پایگاه داده با SQLAlchemy          جلسه ۱۳   آزمون خودکار با pytest
جلسه ۶   عملیات کامل CRUD                   جلسه ۱۴   کلاینت پایتونی
جلسه ۷   رابطه‌ها و ثبت‌نام در دوره          جلسه ۱۵   کلاینت async و یکپارچه‌سازی
جلسه ۸   مهاجرت، صفحه‌بندی و فیلتر          جلسه ۱۶   پروژه پایانی و بازبینی کد
```

## کتاب دوره

پوشه [`book`](book) یک کتاب هفده‌فصلی است که همین دوره را به زبان فارسی و با
توضیح کامل پوشش می‌دهد. خودِ کتاب با HTML و CSS ساخته شده است.

- **فصل صفر** آماده‌سازی محیط کار را توضیح می‌دهد: محیط مجازی، نصب بسته‌ها،
  VS Code، برنامه Bruno، نمایشگر SQLite و در صورت نیاز Docker.
- **فصل‌های یک تا شانزده** دقیقاً برابر جلسه‌های دوره هستند. هر فصل ابتدا مسئله
  را توضیح می‌دهد، سپس نمونه‌کدها را نشان می‌دهد و در پایان به پروژه همان جلسه
  می‌رسد.
- هر فصل با یک جدول جمع‌بندی و چند تمرین عملی تمام می‌شود.

کتاب به شکل آنلاین اینجا در دسترس است و برای خواندنش نیازی به دانلود نیست:

### 📖 [kadoosonline.github.io/FastAPI/book](https://kadoosonline.github.io/FastAPI/book/)

اگر مخزن را دانلود کرده‌اید، فایل [`book/index.html`](book/index.html) را در
مرورگر باز کنید. فهرست مطالب در همان صفحه است.

## ساختار پوشه‌ها

هر جلسه یک پوشه است. داخل هر پوشه این فایل‌ها هست:

```
S07-sqlalchemy-relationships/
├── README.md              هدف جلسه، تقسیم زمان، سرفصل‌ها و فهرست نمونه‌ها
├── exercises.md           تمرین‌های کلاس، تمرین پروژه و تکلیف خانه
├── requirements.txt       کتابخانه‌های لازم برای همین جلسه
├── 01_relationships/      نمونه‌ها، به ترتیب آموزشی
│   ├── models.py
│   ├── 01_one_to_many.py
│   └── ...
└── 02_project/            پروژه آموزشگاه در پایان این جلسه
```

شماره ابتدای هر نمونه، ترتیب آموزشی داخل جلسه را مشخص می‌کند. آخرین پوشه
هر جلسه (`NN_project`) همان پروژه آموزشگاه است و هر جلسه از وضعیت جلسه قبل
شروع می‌کند. پروژه‌ها از جلسه دوم یک مجموعه درخواست Bruno در پوشه `bruno/`
دارند.

## روش استفاده

۱. مخزن را دانلود یا `clone` کنید.
۲. وارد پوشه جلسه مورد نظر شوید و یک محیط مجازی بسازید:

```bash
python -m venv .venv
.venv\Scripts\activate          # ویندوز
source .venv/bin/activate       # لینوکس و مک
pip install -r requirements.txt
```

۳. یک نمونه را اجرا کنید:

```bash
cd 02_path_parameters
python app.py
```

و نشانی <http://127.0.0.1:8000/docs> را در مرورگر باز کنید.

۴. برای پروژه جلسه‌های ۸ به بعد، ابتدا جدول‌ها را بسازید و داده نمونه را وارد کنید:

```bash
cd 03_project
alembic upgrade head
python seed.py
python main.py
```

رمز همه حساب‌های نمونه `Password123` است (`admin@kadoos.ir`،
`teacher@kadoos.ir`، `teacher2@kadoos.ir`، `sara@example.com`، `reza@example.com`).

۵. پوشه `bruno` پروژه را در برنامه [Bruno](https://www.usebruno.com) باز کنید،
محیط `local` را انتخاب کنید و درخواست‌ها را یکی‌یکی یا همه با هم اجرا کنید.

۶. از جلسه سیزدهم، آزمون‌ها را با یک فرمان اجرا کنید:

```bash
pytest
```

## پیش‌نیازها

- گذراندن دوره پایتون پیشرفته، یا آشنایی کامل با کلاس، دکوراتور، مولد،
  مدیر زمینه، استثنا و `async`/`await`.
- پایتون نسخه ۳٫۱۲ یا بالاتر، از [python.org](https://www.python.org).
- ویرایشگر [VS Code](https://code.visualstudio.com).
- برنامه [Bruno](https://www.usebruno.com) برای آزمودن API.
- برای یک نمونه از جلسه پنجم و اجرای اختیاری پروژه با PostgreSQL:
  [Docker Desktop](https://www.docker.com/products/docker-desktop/). بقیه دوره با
  SQLite کار می‌کند و به نصب پایگاه داده نیازی ندارد.

## نکته‌های فنی

- همه توضیحات و مستندات داخل کد به **انگلیسی** نوشته شده‌اند تا کد با هر
  ویرایشگر و هر سیستمی بدون مشکل نمایش داده شود.
- مدل‌های پایگاه داده فقط با سبک جدید و تایپ‌دار SQLAlchemy 2 نوشته شده‌اند:
  `DeclarativeBase`، `Mapped` و `mapped_column`.
- همه پروژه‌ها روی SQLite و PostgreSQL آزموده شده‌اند.
- **هیچ رمز یا کلید واقعی در کد نیست.** مقادیر حساس از فایل `.env` خوانده
  می‌شوند و نمونه آن در `.env.example` هر پروژه آمده است.
- کتاب هیچ فایلی از اینترنت نمی‌خواند و روی کامپیوتر بدون اینترنت هم کامل
  کار می‌کند.
